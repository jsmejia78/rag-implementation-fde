**Task Description**

You are required to select any YouTube video of your choice, extract its transcript, and use it as the knowledge source for a RAG system.

Task: Build a simple RAG pipeline using semantic search.

The system should:

- Extract or obtain the transcript from a YouTube video.

- Split the transcript into meaningful chunks.

- Generate embeddings for the transcript chunks.

- Store the embeddings in a vector database or similarity search index.

- Accept user queries and retrieve the most relevant transcript chunks.

- Generate an answer using the retrieved context.
